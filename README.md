# Sprint_7
Проект 7. Тестирование Api
Структура:
- папка tests содержит все тесты:
  - test_accept_order - Проверка прнятия заказа
  - test_create_courier - Проверка создания курьера
  - test_create_order - Проверка создания заказа
  - test_delete_courier - Проверка удаления курьера
  - test_get_order_by_id_order - Проверка получения заказа по id
  - test_list_orders - Проверка получения списка заказов
  - test_login_courier - Проверка логина курьера
- conftest - Фикстуры
- data - Текстовые данные
- helper - Генерация создания данных
- urls - Урлы
- requirements.txt - Зависимости проекта
Для Установки зависимостей проекта ввести в терминале команду: pip install -r requirements.txt
